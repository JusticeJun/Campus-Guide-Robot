# ADR-005: RGB-D 지도 주행과 위치추정 보호 경계

상태: 카메라 전용 단계의 결정. 현재 다중 센서·ExternalNav 확장은 [ADR-006](ADR-006-multisensor-mission-runtime.md)을 따른다.

## 배경

GPS-only 방식은 넓은 캠퍼스 경로를 주행했지만 좁은 구간의 정밀 위치추정에는 한계가 있었다.
RGB-D 지도와 Nav2를 연결할 때 TF 소유권, 이미지/odometry 시간 정합, 지도 교체와 추적 손실 처리가 필요했다.

## 결정

- 카메라 IMU를 보조 입력으로 쓰는 `rgbd_odometry`가 `odom → base_link`를 전담한다.
- RTAB-Map이 DB 기반 위치추정과 `map → odom`을 전담한다. VO가 처리한 RGB-D를 함께 사용한다.
- 지도 폴더마다 원본 DB·촬영 설정·2D 지도를 보관하고, 주행은 DB 사본/캐시를 사용한다.
- 기본 목표 입력은 Nav2 액션이다. 기존 경로 그래프는 별도 어댑터로 유지한다.
- 위치추정 증거와 명령 유효성을 보호 노드에서 확인하고, FCU 명령 변환은 기존 어댑터에 한정한다.
- `planner`/`validation`은 차량 명령을 연결하지 않는다. `drive`만 명시적으로 연결한다.
- 주행 시간 최적화는 DB 재사용·이미지 전송·계산량에 적용하고 목표 속도 정책과 구분한다.

## 근거와 결과

운영자가 카메라 기반 지도 생성과 지도 주행의 실차 성공을 확인했다. 영상 매칭, TF, 경로, 명령 경계는
회귀 테스트로 검증한다. RViz 초기 위치 입력이나 TF 존재만으로 정합 성공이라고 판단하지 않는다.
카메라가 정상이어도 FCU의 GPS/나침반 추정 오류는 실제 속도·조향을 망가뜨릴 수 있다.
라이다 통합·실시간 장애물 회피·FCU ExternalNav는 이 결정의 구현 범위 밖이다.
ADR-004의 정밀 위치추정 확장 방향을 구현하며, GPS-only 경로의 기존 검증 사실은 유지한다.
