# 하드웨어와 실차 검증 범위

## 구성과 좌표

| 항목 | 적용값 |
|---|---|
| 컴퓨터 | NVIDIA Jetson Orin Nano, ROS 2 Humble |
| 카메라 | Intel RealSense D435if, RGB-D + 카메라 IMU |
| 차량 제어기 | Pixhawk 6C, ArduRover 4.7.1 (2026-10-15 확인) |
| 구동 형식 | Ackermann 조향 |
| 축간거리 / 차체 길이 / 폭 | 0.35 / 0.48 / 0.27m |
| `base_link` | 뒷바퀴 차축 중앙, 지면 위 0.07m |
| 축 방향 | +X 전방, +Y 왼쪽, +Z 위 |
| 차체 범위 | X: −0.07~0.41m, Y: ±0.135m |
| 계획 최소 회전반경 / 보정 명령 최소 반경 | 2.0 / 1.7m |
| 직선 / 급커브 / 명령 상한 | 0.35 / 0.25~0.35 / 0.40m/s |

```yaml
footprint: [[0.41, 0.135], [0.41, -0.135], [-0.07, -0.135], [-0.07, 0.135]]
base_to_camera: [0.3001, 0.0175, 0.2032, 0, 0, 0]  # m, rad
base_to_fcu: [0.25, 0, 0.07, 0, 0, 0]  # 사용자 측정, 본체 중앙 근사 (2026-10-21)
```

카메라 치수는 전면 유리 위치 X=0.3048m, 본체 중앙 지면 높이=0.2732m에
D435if 광학 기준점 보정을 적용한 값이다. 정밀 외부 파라미터 보정 결과는 아니므로 재장착 시 확인한다.
카메라 내부 TF는 RealSense 드라이버가 관리한다.

## 카메라 IMU 준비

검증 당시 커널은 `5.15.148-tegra`, RealSense ROS/librealsense는 `4.58.4/2.58.4`였다.
Jetson 커널의 HID sensor hub 지원이 없어 IMU 수신을 위한 커널 모듈을 별도 준비했다.
해당 기기에 설치된 모듈은 소스 저장소나 diagnostics 삭제 대상이 아니며,
다른 기기에서 이 저장소를 빌드하는 것만으로 IMU 지원이 설치되지는 않는다.
`/camera/camera/imu`와 필터 출력 `/camera/imu` 수신을 확인한다.

## Pixhawk 6C 조향 기준값

2026-10-18 정지 상태에서 사용자 승인 후 FF/P를 적용하고 재확인한 값이다.
ROS launch는 FCU 파라미터를 자동으로 쓰지 않는다.

| 파라미터 | 값 |
|---|---:|
| `ATC_STR_RAT_FF` | 3.0 |
| `ATC_STR_RAT_P` | 1.0 |
| `ATC_STR_RAT_I` / `ATC_STR_RAT_D` | 0.2 / 0 |
| `ATC_STR_RAT_IMAX` | 1.0 |
| `ATC_STR_RAT_MAX` / `ATC_STR_ACC_MAX` | 120 / 120 |
| `MOT_SPD_SCA_BASE` | 1.0 |

오른쪽 원주 시험(0.4m/s, −0.235294rad/s)은 360.2°에서 종료됐다.
마지막 5초 평균 IMU yaw rate는 −0.236421rad/s, FCU 전방 속도 추정값은 0.39420m/s였다.
이는 해당 속도의 오른쪽 조향 응답 확인이며, 모든 커브·왼쪽 조향·독립 실측 속도의 보장은 아니다.
2026-10-22부터 계획 회전반경은 2.0m로 늘리고, 추종 오차 보정을 위한 명령 한계는 1.7m로 유지한다.

### 2026-10-22 저속 조향 보정 (실차 재검증 대기)

0.25m/s 유턴에서 목표 회전속도 0.147rad/s에 대해 실제 추정값은 약 0.092~0.095rad/s,
반경은 약 2.6~2.7m였다. 명령 전달은 정상이었지만 조향 출력은 약 1250µs에 머물렀다.
ArduRover 4.7.1은 `MOT_SPD_SCA_BASE` 이하에서 일반 조향 차량의 I항 증가를 제한한다.
따라서 기존 0.4m/s 원주 시험의 FF/P 응답을 기준으로 다음 초기 보정값을 적용했다.

| 파라미터 | 이전 | 현재 |
|---|---:|---:|
| `MOT_SPD_SCA_BASE` | 1.0 | 0.2 |
| `ATC_STR_RAT_FF` | 3.0 | 6.0 |
| `ATC_STR_RAT_P` | 1.0 | 2.0 |

기준속도보다 빠를 때 조향 출력에 `기준속도/실제속도`가 곱해진다.
새 값은 0.4m/s에서 FF·P의 유효값을 기존 3·1로 유지하고,
0.25~0.35m/s에서는 같은 곡률에 필요한 출력을 확보한다.
FF만 6으로 올리는 설정이 아니라 기준속도와 함께 사용하는 조합이다.
FF 6은 공식 파라미터 설명의 권장 범위(0~3)를 넘는 환산 초기값으로,
FCU의 수락·읽기 검증만 완료했으며 폐루프 안정성과 좌우 추종은 실차 확인이 필요하다.
I/D, 조향 및 스로틀 PWM 범위, Nav2 속도는 바꾸지 않았다.

반경 2m의 확인 목표는 0.25m/s에서 0.125rad/s, 0.35m/s에서 0.175rad/s다.
서보·지면·속도 추정 오차가 있으므로 정지 상태 파라미터 검증을 주행 성공으로 보지 않는다.
백업과 복구 도구는 `~/ros2_ws/backups/fcu/20261022_low_speed_steering/`에 있다.
ROS 환경을 불러온 뒤 시동 해제 상태에서 다음 명령으로 변경한 세 값만 복구한다.

```bash
python3 ~/ros2_ws/backups/fcu/20261022_low_speed_steering/apply_or_restore.py --restore
```

근거: [ArduRover 4.7.1 조향 속도 보정 구현](https://github.com/ArduPilot/ardupilot/blob/Rover-4.7.1/libraries/AR_Motors/AP_MotorsUGV.cpp#L719-L728).

## 운용 한계

카메라 기반 지도 주행은 실차에서 확인했지만, 영상 추적은 조명·블러·시점 차이·수신 지연에 영향을 받는다.
기존 GPS 모드의 차량 제어는 FCU 내부 GPS/나침반 추정에 의존한다.
선택형 [ExternalNav 구성](external_navigation.md)은 이를 카메라 오도메트리로 대체하며 실차 검증은 별도다. 카메라 위치추정 정상과 FCU 추정 정상은 별개다.
이전 시험에서 실제 전진을 FCU가 후진으로 해석하며 스로틀이 상승한 기록이 있었다.
따라서 센서 교체 후에는 실제 방향, QGC 방향, 실제 차속과 FCU 추정 차속을 대조한다.
`SERVO3_REVERSED`는 출력 전기적 방향이며 잘못된 방향 추정을 고치는 설정이 아니다.

추가 전장 장비를 켰을 때 자기장 경고와 GPS 수신 저하가 관찰됐다. 2026-10-19 비교에서
장비 전원 OFF 후 위성 0개/No Fix에서 3D Fix로 회복됐지만 재현 시험까지 완료된 원인 확정은 아니다.
나침반 보정 품질 문제도 남아 있다. 센서를 재배치하고 실제 운용 전원 상태에서 간섭을 확인해야 한다.
작업 브랜치에는 [라이다 융합·감지·회피](sensor_fusion.md)를 추가했다. 야외 이동 검증은 남아 있다.

## 2D 라이다

- SLAMTEC RPLIDAR A1M8-R6360, `/dev/ttyUSB0`, 115200 baud.
- 차량 정면 기준 좌우 100도, 총 200도 사용. 원본 `/scan_raw`, 처리 `/scan_front`.
- 회전 중심: 뒷차축 중앙보다 앞 0.32m, 좌우 중앙. 레이저 측정면 지면 위 0.25m.
- `base_link` 지면 높이 0.07m를 빼서 TF는 `(0.32, 0, 0.18)`m.
- 기본 장착 yaw 0. `lidar.launch.py yaw:=...`(rad)는 TF와 전방 필터에 함께 반영된다.
  실제 방위와 차체 가림은 RViz로 대조한다. 정지 수신 시험에서 약 7Hz였다.

## 저장장치

- OS: 기존 microSD, JetPack/L4T R36.4.7.
- 프로젝트 데이터: KLEVV CRAS C910G M.2 NVMe 2280 500GB, PCIe 3.0 ×4 연결 확인.
- 현재 NVMe ext4 마운트: `/home/ykk` 전체. `~/ros2_ws`는 SSD 안의 실제 디렉터리이며 기존 `~/ssd` 링크 구조를 대체한다.
- 전체 홈 이전 후 `.ros`, 캐시, 개발 도구와 사용자 설정까지 SSD에 저장한다. `/opt/ros`와 시스템 패키지는 SD에 유지한다. 이전 절차는 [실행 안내](navigation.md#홈-전체를-ssd로-옮기기)에 있다.
- 2026-10-22 설치 시 SMART critical warning·media error 0, 사용률 0%, 온도 약 36°C.
- SSD는 저장 I/O를 개선하지만 CPU·RAM을 늘리지는 않는다. 메모리 정책은 별도 검증한다.
